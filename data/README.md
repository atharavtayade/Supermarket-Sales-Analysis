# Dataset Directory

## Supermarket Sales Dataset

This directory is intended to hold the project dataset.

### Dataset Source
- **Name**: Supermarket Sales Dataset
- **Source**: [Kaggle - Supermarket Sales](https://www.kaggle.com/datasets/aungpyaeap/supermarket-sales)
- **File**: `supermarket_sales.csv`

### How to Obtain the Dataset

1. Visit: https://www.kaggle.com/datasets/aungpyaeap/supermarket-sales
2. Click "Download" (requires a free Kaggle account)
3. Extract the downloaded ZIP file
4. Place `supermarket_sales.csv` in this `data/` directory

### Dataset Description

The dataset contains **1,000 sales transactions** from three supermarket branches over approximately three months (January–March 2019).

### Columns

| Column | Description |
|--------|-------------|
| Invoice ID | Unique transaction identifier |
| Branch | Supermarket branch (A, B, C) |
| City | Branch city (Yangon, Naypyitaw, Mandalay) |
| Customer type | Member or Normal |
| Gender | Customer gender |
| Product line | Product category |
| Unit price | Price per unit (USD) |
| Quantity | Number of units purchased |
| Tax 5% | 5% tax on purchase |
| Total | Total including tax |
| Date | Purchase date |
| Time | Purchase time |
| Payment | Payment method (Cash, Ewallet, Credit card) |
| cogs | Cost of goods sold |
| gross margin percentage | Gross margin percentage |
| gross income | Gross income |
| Rating | Customer rating (1–10) |
